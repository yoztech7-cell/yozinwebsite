5. Education (education.html)
6. Contact (contact.html)

TECHNOLOGIES USED

- CSS3

PROJECT STRUCTURE
- HTML files: Website pages
- css/: External CSS stylesheet
- images/: Website images

HOW TO RUN THE WEBSITE
1. Extract the project folder if it is compressed.
2. Open the project folder.
3. Double-click index.html.
4. The website will open in your web browser.
